2일차는 **VAE의 성능을 계속 튜닝하는 수업이라기보다, VAE에서 확인한 생성 품질의 한계를 출발점으로 다른 생성 방법을 비교하는 수업**

```
1일차

Augmentation
→ 사람이 직접 변형

VAE
→ 데이터의 특징을 학습
→ 새로운 이미지 생성 가능성 확인
→ 하지만 Random Sample은 흐릿함

        ↓

2일차

DCGAN
→ 다른 생성 방식으로 Apple 생성

WGAN-GP
→ GAN 학습을 좀 더 안정적으로 만들어 비교

Pretrained Diffusion
→ 사전학습 모델로 더 사실적인 생성 방식 경험

        ↓

어떤 방식의 결과가
실제 학습데이터 후보로 적절한지 비교·검수
```
