# 1. 교과 1~6에서 최종 PBL까지의 전체 흐름

교과 1~6에서 배운 내용은 앞으로 진행할 PBL의 기본 개발 도구입니다.

| 지금까지 배운 내용 | 앞으로 사용하는 곳 |
|---|---|
| 교과 1 Linux | 개발환경, 파일관리, Git, Raspberry Pi·Jetson |
| 교과 2 Python · NumPy · Pandas | 데이터 처리, 분석, 로그, AI 코드 |
| 교과 3 OpenCV | 이미지·영상 처리, 라벨링, 머신비전, 카메라 |
| 교과 4 Machine Learning | 학습·평가, Accuracy, Confusion Matrix |
| 교과 5 Deep Learning | 객체검출, Pose, 생성모델, Fine-tuning |
| 교과 6 GUI | 라벨링 도구와 최종 검사·동작인식 화면 |

즉, 교과 1~6이 기술을 하나씩 배우는 단계였다면, 
교과 7부터는 배운 기술을 서로 연결하여 실제 결과물을 만드는 PBL 단계로 넘어갑니다.

![[Group 7.png]]

전체 과정은 크게 제조 Vision AI와 산업안전 Action AI 두 개의 최종 프로젝트를 향해 진행됩니다.

### 제조 Vision AI 트랙

교과 7에서는 직접 라벨링 도구를 만들면서 AI 학습에 필요한 정답 데이터가 어떻게 만들어지는지 이해합니다.  
교과 8에서는 이 데이터를 이용하여 객체검출 모델을 학습하고 평가하는 과정을 경험합니다.

이후 교과 9의 OpenCV 기반 머신비전, 교과 11의 합성데이터·데이터 보강, 교과 13의 Edge AI와 장치 실행 기술을 더해 최종적으로 교과 14에서 실제 컨베이어·카메라·Jetson을 이용한 제조 제품검사 시스템을 완성합니다.

### 산업안전 Action AI 트랙

교과 10에서는 사람 영상에서 2D Pose와 관절 Keypoint를 추출하고 움직임을 분석하는 방법을 배웁니다.

교과 11에서는 부족한 동작 데이터를 보강하는 방법을 익히고, 교과 12에서는 VICON을 이용해 전문적인 3D 모션데이터가 어떻게 촬영되고 만들어지는지 경험합니다.

이러한 내용을 바탕으로 최종적으로 교과 15에서 PC와 웹캠을 이용한 실시간 동작인식 시스템을 완성합니다.

# 2. 제조 Vision AI 트랙

제조 트랙의 흐름은 정답 데이터를 만들고 → AI를 학습시키고 → 현장 장비에서 실행하는 과정입니다.

![[Pasted image 20260820165917.png]]

### 이 트랙에서 각 교과의 역할

**교과 7 — 라벨링**  
프로젝트를 통해 사람이 이미지에서 이물 위치를 BBox로 표시하여 AI가 배울 정답 데이터를 만듭니다.

**교과 8 — 객체검출**  
프로젝트를 통해 교과 7의 라벨 데이터를 이용하여 AI가 새로운 이미지에서 이물의 종류와 위치를 자동으로 찾도록 학습합니다.

**교과 9 — 머신비전**  
AI가 아니라 OpenCV의 Threshold, Contour, Template Matching 등의 규칙 기반 검사 방법을 배웁니다. 최종 제조 프로젝트에서 필요하면 AI와 함께 사용할 수 있습니다.

**교과 11 — 합성데이터**  
데이터가 부족한 경우 증강·VAE·GAN·Diffusion·3D Graphics 등으로 데이터를 보강하고, 보강 전후 성능을 비교합니다.

**교과 13 — Edge AI**  
Raspberry Pi에서 Edge 실행 구조를 익히고 후반에는 Jetson 환경과 ONNX·TensorRT 배포 구조를 경험합니다.  
이 경험이 교과 14의 실제 Jetson 프로젝트로 이어집니다.

**교과 14 — 최종 제조 PBL**  
실제 컨베이어·조명·산업용 카메라 환경에서 데이터를 다시 촬영하고, 객체검출 모델을 학습한 뒤 Jetson Orin Nano Super에서 실시간 제조검사 시스템으로 완성합니다.

```text
최종 목표
실제 카메라 영상
→ 불량·이물 검출
→ OK / NG 판단
→ 통계·로그
→ Jetson 실시간 실행
```

# 3. 산업안전 Action AI 트랙

산업안전 트랙은 사람의 움직임을 관절 데이터로 바꾸고 → 시간에 따른 동작을 학습하는 과정입니다.

![[Pasted image 20260820170322.png]]

### 이 트랙에서 각 교과의 역할

**교과 10 — 2D Pose**  
웹캠·영상에서 사람의 관절 Keypoint를 추출하고 Skeleton, 관절각도, Sequence 데이터를 이해합니다.

**교과 11 — 데이터 보강**  
필요한 경우 Keypoint 위치·크기·속도 등을 변형해 동작 데이터를 보강합니다.

**교과 12 — VICON 모션캡처**  
전문 모션캡처 장비로 3D Motion을 촬영하고, Shogun → FBX → 3D Motion JSON → 2D Motion JSON으로 이어지는 **모션데이터 제작 Pipeline**을 이해합니다.

**교과 15 — 최종 산업안전 PBL**  
Pose·Keypoint·Sequence와 모션데이터 제작 경험을 바탕으로 **최소 10개 이상의 동작을 분류**하고, 최종적으로 PC + 웹캠에서 실시간 동작인식 시스템을 완성합니다.

```text
최종 목표
웹캠 영상
→ 사람 Detection
→ 2D Pose / Skeleton
→ Keypoint Sequence
→ Action Recognition
→ 동작 결과 · Accuracy · FPS
```

# 5. PBL에서는 이렇게 진행합니다

PBL은 강사가 완성 코드를 주고 그대로 따라 만드는 수업이 아닙니다.

![[Pasted image 20260820170649.png]]

앞으로 모든 프로젝트에서 반복할 질문은 같습니다.

```
1. 무엇을 만들어야 하는가?
2. 입력 데이터는 무엇인가?
3. 정답 또는 판단 기준은 무엇인가?
4. 어떤 모델·규칙을 사용할 것인가?
5. 결과가 맞는지 어떻게 측정할 것인가?
6. 실패한 경우 무엇을 바꿀 것인가?
7. 최종 시스템에서 어떻게 연결할 것인가?
```

# 6. 오늘 시작하는 교과 7의 위치

지금 시작하는 교과 7은 전체 과정에서 아주 중요한 첫 번째 Handoff 지점입니다.

![[Pasted image 20260820170909.png]]

교과 7에서 여러분이 만드는 것은 단순한 GUI 프로그램이 아닙니다.

> 사람이 만든 정답을 AI 학습데이터로 연결하는 첫 번째 도구입니다.

따라서 교과 7에서 가장 먼저 이해해야 할 것은 다음 세 가지입니다.

```text
이미지를 불러온다
→ 사람이 정답 BBox를 만든다
→ 그 정답을 파일로 저장한다
```

이 작은 기능에서 시작하여 앞으로  
데이터 → AI 모델 → 실제 장비 → 최종 서비스까지 확장하게 됩니다.

# 교과 14 제조분야 제품검사 솔루션 - 프로젝트

![[Pasted image 20260820172853.png]]

교과 14에서는 앞서 배운 라벨링·객체검출·머신비전·데이터 보강·Edge AI 기술을 하나로 연결해 실제 제조 검사 시스템을 완성합니다.  
실제 컨베이어와 카메라 데이터를 이용해 모델을 학습하고, Jetson에서 불량·이물을 실시간 검출하여 OK/NG 판정·통계·로그까지 구현하는 트랙 1의 최종 프로젝트입니다.

컨베이어 + 산업용 카메라 + 조명 + Jetson Orin Nano Super를 반드시 사용한다는 조건으로 제작할수 있는 프로젝트는 PBL로 연결된 교과 7프로젝트와 교과 8프로젝트를 연결하여 
김치 이물검출 프로젝트를 진행해볼수 있습니다.

그외

- 전자·기계부품 조립 누락 검사
    - 컨베이어 위에 부품을 흘려보내면서 나사 없음, 부품 누락, 방향 오류, 다른 부품 혼입, 파손 등을 검출합니다.
    - 실제 제조공정의 조립품 품질검사와 가장 비슷해 산업적인 느낌이 강한 프로젝트입니다.
- 제품 포장·라벨 품질검사
    - 박스·병·용기 등을 이동시키면서 라벨 없음, 라벨 위치 불량, 뚜껑 없음, 인쇄 불량, 잘못된 제품/색상 등을 검사합니다.
    - 객체검출에 교과 9의 OCR·OpenCV 규칙검사까지 결합하면 `AI + 머신비전 Hybrid 검사` 프로젝트로 확장하기 좋습니다.
- 재활용품·산업폐기물 자동 분류 시스템
    - 컨베이어 위 물체를 플라스틱, 캔, 종이, 유리, 금속 등 5개 이상 클래스로 검출·분류하고 종류별 통계까지 보여줍니다.
    - Jetson에서 실시간 검출하여 향후 분류 로봇이나 액추에이터와 연결하는 스마트 자동선별 시스템으로 확장할 수 있어 기존 조각김치 프로젝트와 차별화하기 좋습니다.

Jetson에 배포
```
산업용 카메라
      ↓
Jetson Orin Nano Super
      ↓
TensorRT / ONNX
객체검출
      ↓
OK / NG 판정
      ↓
FastAPI
      ↓
웹 대시보드
```

예를 들어 Jetson의 IP가 `192.168.0.50`이라면 학생 PC에서 브라우저로
```
http://192.168.0.50:8000
```
에 접속해서 검사 결과를 보는 방식입니다.

따라서 최종적으로는:
```
[Jetson]
카메라
+ AI 추론
+ 검사 판정
+ FastAPI
+ 로그 저장

       │
       │ HTTP / WebSocket
       ▼

[학생 PC]
Chrome
→ 검사 Dashboard
```

### Tkinter에서 FastAPI로 확장하는 이유

Tkinter로 로컬 GUI 프로그램 구조를 이해한 뒤, FastAPI를 통해 AI 결과를 웹 브라우저와 실시간으로 연결하는 방법을 배웁니다.  
이를 통해 최종 프로젝트에서 AI 모델·장비·웹 대시보드를 하나의 서비스로 통합하는 경험을 할 수 있습니다.

| 교과        | FastAPI 적용   | 학생이 배우는 수준                                 |
| --------- | ------------ | ------------------------------------------ |
| **7**     | ❌            | Tkinter로 라벨링 GUI 완성                        |
| **8**     | △ 굳이 안 넣음    | 객체검출 모델 학습에 집중                             |
| **9**     | ✅ FastAPI 입문 | REST API + 간단한 웹 결과 화면                     |
| **10**    | ✅ 실시간 확장     | WebSocket + Pose/동작 결과 실시간 표시              |
| **11·12** | ❌            | 본래 합성데이터·VICON 내용에 집중                      |
| **13**    | ✅ 배포 실습      | Raspberry Pi/Jetson에서 FastAPI 실행 + 네트워크 접속 |
| **14**    | ✅ 최종 활용      | Jetson + FastAPI + 제조 Dashboard            |
| **15**    | ✅ 최종 활용      | PC + FastAPI + 동작인식 Dashboard              |

- Tkinter: 한 PC에서 실행되는 데스크톱 GUI를 만드는 도구입니다. 화면에 AI 결과를 보여주는 데 적합합니다.
- FastAPI: AI 결과를 REST API / WebSocket으로 네트워크에 제공하는 서버를 만드는 도구입니다. PC, 태블릿, 다른 서버 등 여러 장치가 같은 데이터를 사용할 수 있습니다.

Tkinter도 Python의 `requests` 등을 이용해 다른 서버와 통신할 수는 있습니다. 하지만 Tkinter 자체가 여러 디바이스에 데이터를 서비스하기 위한 API 서버는 아닙니다. 그래서 최종 목표가 
```
AI 결과를 네트워크를 통해 여러 디바이스에서 사용할 수 있는 서비스
```
라면 Tkinter보다 FastAPI 기반으로 가는 것이 훨씬 적절합니다.
